# Rule sources

SpaceLens country packs are planning guidance, not a compliance check. Requirements depend on building type, size and the date of the permit application. Check the current text with your local authority before relying on any value. Every value below was read from the official text on 2026-11-15. "Requirement" is binding text; "Guidance" would be a non-binding general advice (allmänt råd). All values in the packs are now binding requirements.

Sources, read through Finlex's official open-data API (consolidated texts, also published at finlex.fi) and Boverket's rinfo publications:

- Finland: statute 241/2017 (consolidated 2024-11-28), 848/2017 (consolidated 2020-12-02), 1008/2017 (consolidated 2018-02-06).
- Sweden: BFS 2024:7 (fire safety) and BFS 2024:12 (accessibility), both in force 2025-07-01, as published.

## Amendments checked

| Decree | Amendments found | Effect on pack values |

| 848/2017 | 927/2020 (in force 2021-01-01) amends 4 § 3 mom., tables in 13, 15, 16, 23, 26 §, 24, 25 §, 33 § table 11 and 2 mom., 41 §, 43 § | None to the pack values (32, 34, 35 § untouched); table 11 (number of exits) changed |
| 1008/2017 | 127/2018 (in force 2018-02-14) amends 5 § (windows) | None |
| All three | Act 752/2023 (transitional rules for the Building Act): the decrees remain in force | None |

Boverket: the BBR chapters the pack used before (3 accessibility, 5 fire) were replaced by BFS 2024:7 and BFS 2024:12 on 2025-07-01. Boverket states the option to apply the older rules ended on 2026-07-01 (https://www.boverket.se/en/start/laws-and-regulations/national-regulations/building-regulations/). BFS 2024:7 may have been amended after publication (Boverket pages mention BFS 2025:10); the rinfo PDF read is the original text, so the Swedish values are as published and a later change is not ruled out.

## Not confirmed (not in the packs)

- Finland: number of exits by height and use (848/2017 33 §, table 11, amended by 927/2020). The table text could be read but its columns (compartmented, protected, smoke-protected, sprinklers) could not be mapped to rows without the table layout, so no number is given. 33 § 2 mom. does state one exit may suffice in some single-storey cases (lodging with outside access, care for up to ten, small assembly or shop). Extinguisher spacing and smoke alarm coverage were not looked up.
- Sweden: room height. The old BBR 3:311x values (2.4 / 2.7 / 2.4 m) were removed with the repealed chapter and no numeric room height was found in BFS 2024:11 or BFS 2024:12. Extinguisher spacing and alarm coverage were not looked up. BFS 2025 amendments to BFS 2024:7 were not read (Boverket lists BFS 2025:10).
- Sweden: the old general advice values (walk 30 m, one-direction corridor walks, 150-person width) were replaced by the binding values above; the mapped safety setting for longest walk is no longer set from Sweden because the limit now depends on activity class.
- Walking speeds, door flow, occupant area and the other simulation settings stay as the general rules of thumb.
