# Rule sources

SpaceLens country packs are planning guidance, not a compliance check. Requirements depend on building type, size and the date of the permit application. Check the current text with your local authority before relying on any value. Every value below was read from the official text on 2026-11-15; "Requirement" is binding text, "Guidance" is a non-binding general advice (allmänt råd).

Sources: Finland, Finlex (statute 241/2017 and 848/2017, original versions as published; later amendments were not checked). Sweden, Boverket BBR consolidated to BFS 2024:5.

## Not confirmed (not in the packs)

- Finland: number of exits by building height and use (848/2017 table 11, too conditional to simplify); minimum corridor width for wheelchairs; minimum room height (separate decree); extinguisher spacing; smoke alarm coverage.
- Sweden: number of exits (BBR 5:331); dwelling door and corridor widths in standard SS 91 42 21 (paid standard); extinguisher spacing; alarm coverage.
- Walking speeds, door flow, occupant area and the other simulation settings stay as the general rules of thumb.
